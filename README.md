This is an Android application built to facilitate registration and trading of electronic waste, promoting responsible 
disposal and reuse 
1) Designed user-friendly, data entry and category-based browsing to improve adoption and ease of use 
2) Integrated chat features to enhance potential buyers and sellers connections for easier purchases and security of the deals
3) Developed a simulated M-pesa sandbox feature to allow buyers to conduct payments in the app minimizing theft and fraud
4) Uses Luhn's algorithm to verify the correctness of serial numbers
5) Integration with google services allows for easy login and signups as well as protection for all user accounts
